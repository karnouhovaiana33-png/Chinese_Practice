# Чемодан Лунлуна · ДЗ урока 3

Самостоятельное ДЗ по одежде на 25 минут, максимум 30 минут активной работы.
Первое задание — речевая разминка с четырьмя персонажами из слогов.
Затем повторение шести слов, мэтчинг, мэмори, фразы и устный рассказ.
Последний этап — крупная пропись: 9 карточек, 13 разных иероглифов.
Слова 衣服、裤子、裙子、帽子、鞋子、袜子 и знаки 我、要、这、是、的.
Рисунки в свободных клетках и обводка сохраняются; доступно письмо в тетради.

В пакете только ДЗ, его иллюстрации, локальная озвучка и библиотека письма.
Откройте index.html для локального запуска. Для отдельной публикации загрузите
содержимое папки в репозиторий GitHub и выберите Settings → Pages → GitHub Actions.
Публикация не выполняется сборщиком автоматически.

Прогресс хранится только в браузере ученика. Микрофон необязателен.
Записи голоса не отправляются и удаляются при смене экрана.
При общем устройстве используйте отдельные профили браузера для разных учеников.

Иллюстрация дракона создана встроенным image_gen; одежда, чемодан и персонажи
из слогов повторно использованы из уроков. Новые фразы озвучены локальным
Mandarin Microsoft Huihui, образцы слов взяты из комплекта урока.
Лицензии библиотеки письма и её данных находятся в vendor/.
