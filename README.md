# Кирпичики памяти · Chinese Practice

Короткое домашнее задание по китайскому: гласные a/e/o во всех четырёх тонах, шесть животных-пазлов, выбор тона, запись голоса и копирование иероглифов.

| Иероглиф | Пиньинь | Значение |
|---|---|---|
| 猫 | māo | кошка |
| 鸡 | jī | курица |
| 鱼 | yú | рыба |
| 牛 | niú | корова |
| 狗 | gǒu | собака |
| 马 | mǎ | лошадь |

Откройте сайт GitHub Pages. Аккаунт ученику не нужен. Микрофон требует разрешения браузера; если он недоступен, можно повторить слово вслух и продолжить. Записи сохраняются только в IndexedDB браузера ученика и не отправляются на сервер. Автоматической оценки произношения и почерка нет.

Письмо теперь проверяет порядок и направление черт для всех шести знаков. «Посмотреть написание» показывает анимацию; после неё нужно самому написать черты. Есть контур, начальная точка и подсказки. Успешные черты сохраняются после перезагрузки. Для письма в тетради остаётся отдельное самостоятельное подтверждение. Библиотека Hanzi Writer и шесть наборов данных включены локально; лицензии и атрибуция лежат в `vendor/`.

Прогресс сохраняется на устройстве; после очистки данных браузера он исчезнет. Завершённое ДЗ заканчивается проверкой трёх случайных слов. Интерфейс работает с мышью и на сенсорном экране.

## Публикация

В Settings → Pages выберите Source: GitHub Actions. В репозитории подготовлен workflow `.github/workflows/pages.yml`. Он публикует статические HTML, CSS, JavaScript и локальные аудиофайлы без сборки. Основная ветка — `main`.

Гласные и названия животных записаны синтезированным голосом Mandarin; учебные контуры четырёх тонов подготовлены через Praat PSOLA. Первый тон ровный, второй отчётливо поднимается, третий сначала снижается в низкий регистр и затем поднимается, четвёртый падает. Образцы замедлены без понижения тембра голоса. Все записи включены в репозиторий, внешний сервис во время выполнения ДЗ не используется.
