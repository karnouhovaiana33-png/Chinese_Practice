# Город потерянных фраз

[Открыть игру](https://karnouhovaiana33-png.github.io/Chinese_Practice/city/)

Самостоятельное повторение китайского: животные, одежда, цвета, погода. Выберите одного участника. Найдите деталь на панораме, послушайте и повторите слово, выберите ответ, затем вопрос. Верные фразы тоже прослушайте и повторите. После ошибки можно попробовать снова; текст и пиньинь открываются по желанию.

Игра проверяет выбор фраз. Повторение вслух ученик отмечает сам; автоматической оценки произношения нет. Прогресс сохраняется в браузере. Вся игра, изображение и записи включены в один index.html.
